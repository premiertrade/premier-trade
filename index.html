Questions fréquentes

Que contient la version gratuite ?

Les niveaux 1 et 2, le graphique en 2D et les moyennes mobiles. Le Pro ajoute les niveaux 3 à 5, la vue 3D, le rendu HD 4K et plus d’outils.

Comment j’obtiens mon code Pro ?

Dès que ton paiement est validé, tu reçois ton code par e-mail. Tu le saisis une fois dans le jeu et le Pro reste activé sur cet appareil.

Est-ce de l’argent réel ?

Non. Tout est fictif. Le jeu n’est relié à aucun compte ni à aucun courtier.

Les graphiques sont-ils de vrais cours ?

Non. Ils sont générés au hasard à chaque manche, ce qui permet de s’entraîner à l’infini.

Est-ce que je vais gagner de l’argent en trading ?

Le jeu ne promet aucun gain. Il enseigne les bases, et le vrai trading comporte un risque de perte en capital.

Faut-il installer quelque chose ?

Non. Le jeu s’ouvre directement dans le navigateur.
